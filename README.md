# monitorDormilon

Proyecto de Sistemas Operativos (Op2026) — JPino / Lrojas.

## Requisitos

- JDK 21
- Maven 3.9+

## Uso

Compilar:

```bash
mvn clean package
```

Ejecutar los tests:

```bash
mvn test
```

Ejecutar:

```bash
java -jar target/monitorDormilon-1.0-SNAPSHOT.jar
```

## Estructura

```
src/main/java/edu/operativos/monitordormilon/   código fuente
src/test/java/edu/operativos/monitordormilon/   pruebas JUnit 5
```
